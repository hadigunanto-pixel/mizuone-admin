Koneksi Supabase

Masukkan kredensial Supabase Anda untuk menghubungkan formulir secara langsung ke database.

Gunakan key berlabel "anon" "public" di dasbor Supabase Anda. Kunci rahasia "service_role" dilarang demi keamanan.

Folder Aset Lokal

Agar logo resmi Logo MizuOne (1).png dan favicon DSM LOGO.jpg dapat termuat otomatis, pastikan kedua file berada di folder yang sama dengan file HTML ini:

C:\Users\USER\OneDrive\AI\Hadi Brain\Area\Kerja\Perusahaan\Dinasty Sahabat Mulia\Marketing\Aset\

Klik jalur abu-abu di atas untuk menyalin cepat.

Cara Mencari Public Anon Key

  1. Buka dashboard proyek Supabase Anda.
  2. Di menu sebelah kiri bawah, klik menu Project Settings (ikon roda gigi).
  3. Pilih menu API di bawah kategori Settings.
  4. Cari kolom `anon` `public` di bawah panel Project API keys.
  5. Salin nilainya, lalu tempelkan ke kolom kunci di atas!

Hindari menyalin dari kolom `service_role` `secret` karena browser mendeteksi dan memblokirnya otomatis.

Mode Tanpa API

Jika tidak ingin memasukkan API Key, Anda bisa tetap menggunakan form ini di tab "Generator SQL" untuk menghasilkan perintah SQL bebas eror yang bisa langsung dijalankan di Supabase SQL Editor.

Registrasi Manual Teknisi (Sesuai Kolom Database Nyata)

Mendaftarkan teknisi baru dengan pemetaan lengkap termasuk Telegram User ID, Chat ID, dan Wilayah Kerja.

Registrasi & Penugasan Mesin (Assignments)

Mendaftarkan nomor mesin lapangan ke tabel `machine_assignments` lengkap dengan nama lokasi ramah manusia.

Kenapa Metode SQL Ini Sangat Aman?

Metode ini mengabaikan kolom `id` (sehingga Supabase otomatis menghasilkan UUID acak sistem yang valid) dan menjamin relasi grup mesin terpenuhi, menghindarkan Anda dari segala jenis error kendala PostgreSQL.
