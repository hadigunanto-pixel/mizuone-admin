Koneksi Supabase

Masukkan kredensial Supabase Anda untuk menghubungkan formulir secara langsung ke database.

Gunakan key berlabel "anon" "public" di dasbor Supabase Anda. Kunci rahasia "service_role" dilarang demi keamanan.

Folder Aset Lokal

Agar logo resmi Logo MizuOne (1).png dan favicon favicon.jpg dapat termuat otomatis, pastikan kedua file berada di folder yang sama dengan file HTML ini:

C:\Users\USER\OneDrive\AI\Hadi Brain\Area\Kerja\Perusahaan\Dinasty Sahabat Mulia\Marketing\Aset\

Klik jalur abu-abu di atas untuk menyalin cepat.

Uji Aliran n8n

Setelah berhasil mendaftarkan mesin dan teknisi, Anda bisa beralih ke tab "Simulator Alarm" untuk menembakkan sinyal pengujian langsung ke skema n8n Anda.

Registrasi Manual Teknisi (Sesuai Kolom Database Nyata)

Mendaftarkan teknisi baru dengan pemetaan lengkap termasuk Telegram User ID, Chat ID, dan Wilayah Kerja.

Registrasi & Penugasan Mesin (Assignments)

Mendaftarkan nomor mesin lapangan ke tabel `machine_assignments` lengkap dengan nama lokasi ramah manusia.
